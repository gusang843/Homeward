# Homeward

군대 전역일과 취업준비를 함께 관리하는 웹 서비스

## 📌 프로젝트 소개

**Homeward(집가는 날)**는 군대 전역을 준비하면서 취업도 함께 준비할 수 있도록 만든 웹 서비스입니다.

전역 예정일을 등록하여 전역 D-Day를 확인하고, 취업을 위해 지원하는 기업과 일정을 한 곳에서 관리할 수 있습니다.

## 🎯 개발 목적

군 복무 중이거나 전역을 앞둔 사람이 전역일까지 남은 시간을 확인하면서 취업 준비도 체계적으로 관리할 수 있도록 하는 것을 목표로 개발했습니다.

## ✨ 주요 기능

- 회원가입 / 로그인 / 로그아웃
- 전역 예정일 등록 및 수정
- 전역 D-Day 확인
- 지원 기업 등록 / 수정 / 삭제
- 기업별 지원 상태 관리
- 지원 마감일 관리
- 취업 일정 등록 / 수정 / 삭제
- 일정별 D-Day 확인
- 기업 검색 및 상태별 필터링
- 취업 준비 현황 통계
- 마이페이지 회원정보 관리

1. 회원가입

## 💡 프로젝트를 통해 배운 점

이번 프로젝트를 통해 Next.js를 이용한 웹 서비스 개발 과정을 경험했습니다.

특히 프론트엔드 화면뿐만 아니라 API와 MongoDB를 연결하여 데이터를 저장하고 조회, 수정, 삭제하는 CRUD 기능을 직접 구현하면서 웹 서비스의 전체적인 동작 과정을 이해할 수 있었습니다.

또한 개발 과정에서 발생하는 오류를 직접 확인하고 해결하면서 문제 해결 능력을 키울 수 있었습니다.
